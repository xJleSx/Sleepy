# Sleepy Agent Instructions

## Git

- Разрешено создавать локальный commit после завершения согласованной задачи и успешных проверок.
- Push выполнять только по отдельной явной команде пользователя.
- Перед commit проверять `git status` и `git diff`; коммитить только файлы текущей задачи.
- Не коммитить секреты, токены, сборочные артефакты и временные файлы.
- Push выполнять только в текущую ветку `origin`.
- Не делать force-push, push тегов, amend, rebase, reset --hard, clean или удаление веток без отдельного разрешения.
- Если push отклонён, остановиться и сообщить; не форсировать.

## Project

- Не менять аудиоалгоритм, MODEL 0.1, исходные WAV и результаты экспериментов без отдельного согласования.
- Для правок UTF-8 использовать инструменты edit/write, а не PowerShell `Set-Content`.
- Новый код писать без лишних комментариев.
