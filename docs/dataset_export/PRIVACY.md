# Privacy и безопасность экспорта 0.1

## Разрешённые данные

Экспортируются только event-фрагменты WAV и минимальные metadata: псевдонимные ID, consent, устройство, сессия, границы, checksum и privacy-статус. Запрещены ФИО, телефоны, адреса, email, IMEI, Android ID и устойчивые аппаратные идентификаторы.

## Consent

Экспорт возможен только при:

- `consent.status = active`;
- scope `dataset_research`;
- известных допустимых scopes;
- `guardian_consent = true`, если `minor_involved = true`.

Consent UI в приложении отсутствует. Вызывающий код обязан передать подтверждённые данные; движок не создаёт и не подразумевает согласие.

## Privacy review

Допустимые статусы: `not_reviewed`, `approved_internal`, `approved_restricted`, `approved_public`, `rejected`.

`rejected` блокирует экспорт. `approved_*` несовместим с флагом `unknown`. `not_reviewed` разрешён только для внутреннего черновика и всегда даёт предупреждение «публикация запрещена».

При экспорте значение по умолчанию — `not_reviewed` и `unknown`; это не означает разрешение на публикацию.

## Локальность

Экспорт выполняется локально. Сеть, облако, ASR, распознавание речи и внешние сервисы не используются. Новые зависимости не добавлялись.

## Удаление

Удаление участника удаляет только копии внутри экспортированного пакета:

- participant sidecar;
- связанные session, recording и QC sidecar;
- audio-каталог участника;
- device sidecar, если он не используется другими сессиями;
- идентификаторы из manifest и README.

Исходные WAV Sleepy не удаляются. Перед удалением проверяется целостность пакета по manifest; при несовпадении SHA-256 или размера удаление отклоняется.

## Ограничения

- Legacy-записи без точных content-границ не экспортируются.
- Нет автоматической redaction и privacy review.
- Пакет не является публичным релизом.
- Перед публикацией требуются DPIA, privacy review, проверка consent и retention policy.
